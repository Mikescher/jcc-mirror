The binary is a plain HTTP(S) download. Its Last-Modified is what decides whether it is newer. It is checked for the ELF magic and the size the server promised, then run once with --version before anything is renamed — the failures worth catching here are a truncated download, an error page saved as a binary and a binary for the wrong architecture. The daemon then re-execs, keeping its PID and its container. If the new binary does not survive its first minute the supervisor puts the old one back by itself, and that binary is not offered again.
