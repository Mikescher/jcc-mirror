One operation runs at a time by design: the engine moves one file at a time and the scheduler walks the pairs in priority order, so the buttons are disabled while anything is in flight. Plan counts what a sync would do and changes nothing. Adopt matches what is already on disk against the publisher by size, which is what the USB bootstrap needs before the first sync.
