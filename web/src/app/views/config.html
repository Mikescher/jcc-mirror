Pairs

A pair is one directory of the publisher's share mapped onto one directory here; nothing is mirrored until one exists. In additive mode the tree here only ever grows — what the publisher no longer has is kept. In mirror mode it is quarantined here too, behind the deletion guards. A pair is additive until it is told otherwise, which is the point: run additive-only until the diff is trusted.
