The binary is fetched from the same share the mirror reads, so the publisher needs nothing new. It is checked for the ELF magic and the size the server promised, then run once with --version before anything is renamed — the failures worth catching here are a truncated download and a binary for the wrong architecture, not a malicious one: the transport is a private tunnel. The daemon then re-execs, keeping its PID and its container. If the new binary does not survive its first minute the supervisor puts the old one back by itself, and that binary is not offered again.
